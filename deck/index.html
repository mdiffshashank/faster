Building Faster UI

Delivering a production React 19 UI design library from requirement brief to release.

Input: ./doc/faster-lib-requirements.md
Goal:
  • Architect a production-ready React UI library.
  • Integrate Tailwind CSS synced with Figma tokens.
  • Enforce zero hardcoded color literals.
  • Ensure 100% WCAG accessibility compliance.
  • Write test cases using Jest & RTL.
  • Implement E2E testing suites with Cypress.
  • CI/CD via Github Actions , deployment of Storybook & publish.

Phase : 00

System Guardrails

Pre-flight policies enforcing non-negotiable architectural standards.

01 Shift-Left Policy Engine — Zero raw hex color literals & mandatory WAI-ARIA roles.
02 Architecture Decision Records — Mandatory numbered ADR logs for all tooling choices. 
# System Guardrails Policy
Rule 1: Zero hardcoded hex color literals in JSX / CSS. Use CSS variable tokens.
Rule 2: All interactive components MUST implement WAI-ARIA roles & focus traps.
Rule 3: Every architectural decision MUST generate a numbered ADR log.

Phase : 04

GitHub Actions CI/CD Pipeline

Workflow automation configured via .github/prompts/phase-04-github-actions-ci-cd.prompt.md.

01 CI Verification (job: ci) — Runs 10 sequential quality gate steps covering formatting, linting, type checks, unit/component tests & smoke builds.
02 CD Release (jobs: publish-npm, deploy-storybook) — Automatically publishes package to NPM and deploys live Storybook playground to GitHub Pages. 
# .github/workflows/ci.yml Steps
jobs:
  ci:
    steps:
      - Checkout repository
      - Setup Node.js 20
      - Install dependencies
      - Check formatting
      - Lint
      - Type check
      - Jest tests
      - Cypress component tests
      - Smoke-build Storybook
      - Smoke-build library
  publish-npm:
    steps:
      - Build & Publish to NPM
  deploy-storybook:
    steps:
      - Build & Deploy to GitHub Pages
